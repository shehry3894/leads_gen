Install & first launch

All builds — macOS, Windows, Linux — live in the same Google Drive folder. Open it, grab the file for your OS, then follow the steps below.

  1. From the Drive folder, download the macOS build (the file named leads_gen — no extension). Drop it into your Applications folder (or anywhere you like — ~/Downloads works too).
  2. First launch — dismiss the Gatekeeper warning. Because we don't code-sign the binary yet, macOS will refuse to open it on first double-click. Instead, right-click the file → Open → confirm the dialog. You only need to do this once.
    Prefer the Terminal? Run this instead. 
    xattr -d com.apple.quarantine ~/Applications/leads_gen
  3. The app opens in your browser at http://localhost:8501 (a small Terminal window will also appear — that's the app server; keep it running).
  4. You're in trial mode by default — 3 results per scrape. To unlock the full cap, follow Activate your license below.
  1. From the Drive folder, download the Windows build (leads_gen.exe). Save it to a folder of your choice — Documents\leads_gen\ works well; keep the .exe in its own folder so the app's logs/, leads_gen_output/, and license.key live next to it.
  2. First launch — dismiss the SmartScreen warning. Because we don't code-sign the binary yet, Windows Defender SmartScreen may say "Windows protected your PC". Click More info → Run anyway. You only need to do this once.
  3. The app opens in your browser at http://localhost:8501 (a small Command Prompt window will also appear — that's the app server; keep it running).
  4. You're in trial mode by default — 3 results per scrape. To unlock the full cap, follow Activate your license below.
  1. From the Drive folder, download the Linux build (the file named leads_gen — no extension) into a folder of your choice, e.g. ~/leads_gen/.
  2. Mark it executable (once, right after download): 
    chmod +x ~/leads_gen/leads_gen
  3. Run it from a terminal: 
    ~/leads_gen/leads_gen
    The terminal stays open (that's the app server; keep it running) and the app opens in your default browser at http://localhost:8501.
  4. You're in trial mode by default — 3 results per scrape. To unlock the full cap, follow Activate your license below.
Distro compatibility. The Linux build is compiled on Ubuntu 22.04 (x64) and works on most recent glibc-based distros. If it fails to launch on yours (older glibc, musl-based distros like Alpine, or ARM), email shehry3894@gmail.com with your distro + uname -a output.

Activate your license

Licenses are tied to your machine — one license per computer, works fully offline once installed.

  1. Launch the app. In the left sidebar, look for the box labeled Machine fingerprint. It's a 64-character code that uniquely identifies this computer. Click the copy icon next to it.
  2. Send us your fingerprint. Email shehry3894@gmail.com with the subject line Request for Leads Gen License and include:
    • The fingerprint you copied
    • How many leads you want per run (your license cap)
    • Your desired license duration
  3. You'll receive a license key — a long base64 string. Copy the whole thing.
  4. Paste it into the app. The sidebar has a License key text field — paste the key there and click Activate.
    Or install the key manually

    Create a file called license.key in the folder next to the app, containing just the license key on one line:

    echo "PASTE_YOUR_LICENSE_KEY_HERE" > leads_gen/license.key
  5. Restart the app. The sidebar should now show Licensed in green with your expiry date and max-results cap.
Trial mode Without a license the app runs in trial mode — capped at 3 results per scrape. Perfect for kicking the tires. When you're ready, follow the steps above to unlock the full cap.
Machine-bound & non-transferable A license issued for machine A won't validate on machine B. If you switch computers (new laptop, reinstalled OS, wiped Windows/macOS/Linux install, etc.) you'll need a fresh license — send us the new fingerprint and we'll issue one.

Using the app

Two modes: start a new Excel, or append to one you already have.

Start fresh

  1. Type your query — anything you'd type into Google Maps. E.g. gyms in New York, dental clinics in Dublin, coffee shops in Brooklyn.
  2. Set max results. Bounded by your license cap. In trial mode, capped at 3.
  3. Click Run. Progress and per-business logs stream to the sidebar in real time.
  4. If you've run this query before, a prompt appears. The app auto-names the output after your query (e.g. gyms_in_New_York.xlsx). If a file with that name already exists in leads_gen_output/, a dialog opens with three options:
    • Discard & scrape fresh — overwrite the existing file with only the new results.
    • Append to existing — merge the new results into the existing file; duplicates (by website URL, or name + address if no website) are removed automatically.
    • Cancel — do nothing, keep the existing file untouched.
  5. A second Chrome window will open — that's the app driving Google Maps to gather results.
    Don't touch the Chrome window while it's working. Do not close it, do not click inside it, do not navigate anywhere, and do not type in the search bar. If it's in your way, minimize it (yellow button on macOS, _ on Windows) — that's safe. Anything else will interrupt the scrape and you'll have to start over. It closes itself automatically when the run finishes.
  6. Your Excel lands in a folder called leads_gen_output/ right next to the app.

Append to an existing file

Choose Append to existing, point at your prior Excel, and run a new query. New rows merge in and duplicates (by website, or name + address if no website) are removed automatically.

What each row contains

Name Google Maps Link Address Phone WhatsApp Website Rating Review Count * Facebook Instagram Twitter LinkedIn YouTube Pinterest TikTok Threads Snapchat Emails Scraped Time

* Review Count is best-effort — Google Maps sometimes serves a "limited view" of the place panel that omits the count. Rating always comes through.

Troubleshooting

Common issues and how to fix them. Click any question to expand.

The app won't open — my OS is blocking an unsigned binary

All three builds are currently unsigned, so every OS puts up a first-launch warning. Once you approve it, you never see it again.

macOS (Gatekeeper — "damaged" or "unidentified developer"):

  • Right-click the leads_gen file in Finder → Open → confirm the dialog, or
  • Terminal: xattr -d com.apple.quarantine ~/Downloads/leads_gen (adjust the path).

Windows (SmartScreen — "Windows protected your PC"):

  • Click More info in the blue dialog → Run anyway.
  • If your antivirus quarantines the file, add the folder to its exclusions.

Linux ("permission denied" or nothing happens on double-click):

  • Make it executable: chmod +x ~/leads_gen/leads_gen
  • Run from a terminal to see error output: ~/leads_gen/leads_gen
"License required" — but I already installed my license

The license.key file has to live right next to the app binary, not in your home folder or anywhere else. Check:

  • File is named exactly license.key — not license.key.txt. Both macOS Finder and Windows Explorer hide known extensions by default, so a stray .txt can be invisible.
  • File is inside a folder called leads_gen/ next to the app.
  • File contains just the license key on a single line — no extra whitespace, no line wrapping.

Easiest: paste the key into the sidebar's License key field and click Activate — the app writes the file for you.

"License is not valid for this machine"

Licenses are locked to the machine that produced the fingerprint. This message means the license was issued for a different computer.

Common causes:

  • You copied the license from another computer.
  • You reinstalled your OS or restored from a backup that changed the machine ID.
  • You're running the app inside a VM whose hardware ID changes between boots.

Fix: grab the new fingerprint from the sidebar and email us — we'll issue a fresh license.

I only got 3 results even though I asked for more

You're in trial mode. Either:

  • No license is installed (check the sidebar — does it say Trial or Licensed?), or
  • The trial-mode button in the sidebar was clicked, which forces the 3-result cap for the current session.

Activate a license (see above) or restart the app to clear the trial flag.

"Chrome not found" or the browser fails to start

The scraper drives Google Chrome. It has to be installed at the standard location. Fix:

  • Install (or reinstall) Chrome from google.com/chrome.
  • If Chrome is installed but the app can't find it, quit the app, launch Chrome once manually, close it, then relaunch the app.
  • If you use a Chrome-based alternative (Brave, Edge, Arc), install regular Chrome alongside it — the scraper expects Chrome specifically.
My IP is getting blocked — or results come back empty

Google Maps rate-limits aggressive scraping. If runs start returning empty results, showing a captcha, or the "limited view" banner:

  • Wait 30–60 minutes before retrying. Rate limits reset quickly.
  • Use a residential IP — home or office Wi-Fi. Datacenter and VPN IPs (especially popular ones) get flagged fast.
  • Break large runs into smaller batches — 30–50 at a time is safer than 500 in one go.
  • Space out identical queries — repeatedly running the same search from the same IP is the fastest way to get flagged.
  • Vary queries — different cities or business types spread the load naturally.

If your IP stays blocked for hours, switch networks (hotspot from a phone works) to confirm it's IP-based, then wait it out on the original network.

"Cannot save Excel" — file is locked or in use

The output file is open in Excel, Numbers, or LibreOffice. Close the file in the other program, then click Run again. You can spot a locked file by a hidden file called .~lock.filename.xlsx# next to it.

I accidentally closed / clicked / navigated the Chrome window mid-scrape

The scrape will fail or return partial results — the app relies on that Chrome window staying on the exact page it navigated to. There's no way to recover a run once the window is disturbed.

Fix: click Run again to start a fresh scrape. If the Chrome window is still open but broken, close it manually and re-run — the app will spawn a new one.

To avoid this next time: if the window is in your way, minimize it (yellow button on macOS, _ on Windows). Don't close it, don't click inside it, don't navigate — just minimize. It closes itself when the scrape finishes.

The Review Count column is empty

Google Maps sometimes serves a "limited view" of the place panel to headless sessions and doesn't include the review count in it. Rating still comes through, but the count is best-effort. This is a Google-side behavior — nothing on your end is broken.

If review counts matter to you and you're seeing them consistently blank, let us know and we can look at alternate strategies (they cost more time per business but can be more reliable).

The app is running but the browser tab never opens

Some OSes (macOS in particular) block the auto-open. Open your browser manually and go to http://localhost:8501. If that also fails, another program is using port 8501 — quit any other Streamlit apps (or reboot) and try again.

Where are the log files if I need to send them to support?

Every session writes a timestamped log to a logs/ folder right next to the app. Files look like app_2026-07-22_14-01-01.log. If you email support about an issue, attaching the log from the failing run helps us diagnose it fast.

FAQ

Where does my scraped data end up?

An Excel file (.xlsx) in a folder called leads_gen_output/ right next to the app. File name = your query with underscores. Example: query "gyms in New York" → leads_gen_output/gyms_in_New_York.xlsx.

Can I use my license on multiple computers?

No — one license per machine. Each computer has a unique fingerprint. If you need multi-machine coverage (multiple laptops, an office setup, etc.), reach out and we'll price a multi-seat license.

What happens if I get a new computer?

Install the app on the new machine, grab the new fingerprint from the sidebar, and email us. We'll issue a fresh license — no charge if you're within your current license term.

Does the app phone home or send data anywhere?

No. Licensing is fully offline — the license key contains everything needed to validate locally. The scraper does hit two things: Google Maps (via Chrome, exactly like a normal browser session) and the target businesses' own websites (to extract emails and social links). Nothing is sent to us.

Can I scrape the same query twice and merge the results?

Yes, two ways:

  • Start fresh with the same query — the app notices the existing file and pops a dialog asking whether to Discard & scrape fresh, Append to existing, or Cancel. Pick Append.
  • Append to existing mode — point at any prior Excel and run any query. New rows are merged in.

Either path deduplicates by website URL, or by name + address when a row has no website.

How accurate are the emails?

Emails are pulled from the business's own website when it exists — same as opening the site and reading the "Contact" page. Reliable when a site links a real email; not present when businesses only offer a contact form. Obvious placeholders like you@example.com and email-tracker beacons are filtered out.

What about GDPR / privacy?

You're scraping publicly listed business contact info — the same data you'd get by clicking through Google Maps and each website manually. That said, how you use the data is on you: cold outreach to individuals in the EU, UK, and several US states has consent and disclosure requirements. Consult local law before mass-emailing.

How do I update to a new version?

Download the new app file and replace the old one. Your license.key and leads_gen_output/ folder are preserved as long as they sit next to the new binary. Your license keeps working — same machine, same fingerprint.

Can I run it on a schedule or from the command line?

The shipped app is GUI-only (Streamlit). A CLI version exists but isn't currently bundled with the binary. If you need scripted / scheduled runs, email us — we'll look at bundling the CLI.
